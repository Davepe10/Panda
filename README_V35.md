# Pandalandia V35 — App-first + Cocker 3D articulado

- Rediseño global oscuro/ambiental para que la interfaz se perciba como aplicación y no como dashboard web.
- Mobile: experiencia edge-to-edge, safe areas, navegación inferior flotante y escenas a pantalla completa.
- Tablet/desktop: rail lateral compacto y contenido centrado, sin topbar web tradicional.
- Mundo: escena 3D en tiempo real hecha con Three.js/R3F, sin foto del Cocker como representación principal.
- Cocker: rig articulado por jerarquía de grupos (cabeza, orejas, 4 patas y cola), locomoción en tiempo real, giro, caminar, correr, sentarse, descansar y reacciones.
- Materiales de pelo procedural y silueta de Cocker con orejas largas, pecho claro, patas con flecos y accesorios 3D básicos.
- No depende de assets 3D de pago ni de APIs externas para la mascota.
- Mantiene Supabase, juegos, tienda, armario, jardín, expediciones y progreso existentes.

Nota: es un Cocker 3D procedural/articulado orientado a móvil. No se presenta como escaneo fotogramétrico ni como asset cinematográfico de pago.
