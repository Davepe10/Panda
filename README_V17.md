# Pandalandia V17 — Ultra Pet Visual Pass

V17 parte de V16 y mantiene progresión, tienda, ropa, accesorios, acciones, monedas y XP.

## Cambios gráficos
- Material físico con sheen para simular pelo suave.
- Capas de mechones 3D sobre cabeza/cuerpo para romper la silueta plástica.
- Ojos con iris, pupila, córnea/brillo y reflejos adicionales.
- Bigotes 3D y detalles faciales nuevos.
- Iluminación y cámara reajustadas para un look más natural.
- HUD reducido y más transparente para dejar a la mascota como protagonista.
- Ajustes mobile-first para iPhone/Android.

## Base de datos
Si ya ejecutaste `MIGRAR_DESDE_V15_A_V16.sql`, V17 no necesita SQL nuevo.

## Nota visual
Es el máximo salto posible manteniendo el sistema procedural del proyecto y coste S/0. Para fotorealismo cinematográfico real se requieren assets GLB/GLTF de alta calidad, rig profesional y texturas PBR específicas por especie.
