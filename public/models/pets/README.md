# Pet models

## V20
`cocker.glb` está incluido localmente y se sirve desde `/models/pets/cocker.glb`.

El modelo fue generado para este proyecto y se distribuye junto con Pandalandia. Sus nodos principales (`Head`, `Ear_L`, `Ear_R`, `Tail`, `Tongue`, `Leg_FL`, `Leg_FR`, `Leg_BL`, `Leg_BR`) están nombrados para que `Pet3D.tsx` pueda animarlos por código.

Los demás animales mantienen sus fuentes/fallbacks de V19.
