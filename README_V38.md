# Pandalandia V38 — Premium Native App

V38 reemplaza el aspecto de "web con tarjetas" por una composición app-first:
- rail oscuro con iconos en desktop;
- app bar real en móvil;
- navegación inferior flotante oscura;
- hero con profundidad y jerarquía visual;
- home en bento premium;
- Mundo scene-first: Mia es el foco, no los paneles;
- paleta unificada espresso / ivory / dusty rose / sage / champagne;
- controles de cuidado compactos y ordenados;
- el Cocker continúa usando CockerRealtime3D en runtime;
- no requiere migración SQL nueva desde V37.
