# Migración V9 → V10

No hay cambios obligatorios de base de datos para V10.

1. No ejecutes SQL adicional si V9 ya está funcionando.
2. Reemplaza el código del repositorio por V10.
3. Haz push a GitHub.
4. Espera el deploy de Vercel.
5. Prueba con ambas cuentas que A vea el nombre de B y B vea el nombre de A.

Si algún miembro antiguo no tiene `display_name`, entra nuevamente al onboarding o actualiza ese nombre antes de esperar que aparezca personalizado. Los nuevos registros ya exigen nombre.
