# Pandalandia V29 — Premium Native Pet Experience

V29 focuses on the deployed issues visible on real iPhone screenshots:

- 3/4 responsive camera so the Cocker body is not hidden behind its head.
- Full-pet framing for narrow portrait phones, landscape, tablets and desktop.
- Mobile-first native-app shell: compact header, segmented world navigation, immersive 3D stage, compact needs sheet and horizontal action dock.
- Canvas no longer owns vertical gestures; page scrolling remains natural.
- Stronger Cocker anatomy pass: smaller eyes/highlights/nose, longer muzzle, slimmer head, longer/narrower ears and refined chest proportions.
- PWA manifest + 192/512 icons + standalone metadata. When installed to the Home Screen, browser URL chrome is removed by the OS.
- No SQL migration is required from V28.

Important: browser chrome (Safari/Chrome URL bar) cannot be removed by a website while it is open as a normal browser tab. Install Pandalandia to the Home Screen to use the standalone app presentation.
