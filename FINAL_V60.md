# Pandalandia 60.0.0

Production-candidate rebuild focused on the issues verified in the desktop photo:

- Document/body owns vertical scrolling on desktop. The left rail is fixed independently.
- Strong final contrast rules prevent pale text on pale cards.
- Premium canvas/background applied to all principal modules.
- World layout uses scene-first composition and a sticky desktop control console.
- Mia uses only `CockerUser300K` for the Cocker path; the old procedural Cocker is not imported.
- The unrigged STL now has intentionally visible whole-model movement for walk, bark, sniff, pant, lick, play/wag, scratch, stretch, sit and sleep.
- All old locally synthesized pet WAV files were removed.
- Pet audio now points only to real recorded dog/foley sources documented in `public/sounds/REAL_AUDIO_SOURCES.md`.
- No Supabase migration was added.
