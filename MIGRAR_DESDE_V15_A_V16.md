# Migrar Pandalandia V15 → V16

1. Abre Supabase → SQL Editor.
2. Ejecuta una sola vez `supabase/MIGRAR_DESDE_V15_A_V16.sql`.
3. Después sube el código completo V16 a GitHub/Vercel.

La migración no borra monedas, XP, mascota, partidas, jardín ni inventario previo. Añade el catálogo ampliado, niveles de compra, armario/equipamiento y acciones especiales con cooldown.
