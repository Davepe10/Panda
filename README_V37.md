# Pandalandia V37 — Premium Organized App

Cambios principales:
- WorldHub usa realmente `CockerRealtime3D`; se retiró el uso del Cocker fotográfico para la mascota Cocker.
- Mascota siempre encuadrada dentro de una escena 3D con aspect ratio controlado en móvil y ancho máximo en desktop.
- Paleta premium unificada: marfil cálido, espresso, rosa empolvado, salvia y champagne.
- Jerarquía reorganizada: identidad de mascota -> tabs -> escena -> cuidados -> comportamiento.
- Móvil: escena completa sin paneles superpuestos; controles debajo; navegación inferior fija.
- Tablet: escena arriba y controles organizados.
- Desktop: rail lateral + escena y panel de cuidados en dos columnas.
- No requiere migración SQL nueva respecto de V36/V35.
