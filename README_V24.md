# Pandalandia V24 — Mobile Realism & UX

- El canvas 3D ya no captura el scroll vertical en móvil.
- Cámara responsiva para centrar la mascota y mostrar mejor la habitación.
- Se retiró OrbitControls del hogar para evitar conflictos de gesto.
- Acciones diferenciadas: caminar, comer/beber, ladrar, olfatear, lamer, rascarse, estirarse, sentarse/dormir y sacudirse.
- Sonidos locales para ladrido, olfateo, jadeo, lamido, comer, beber, jugar y sacudirse.
- HUD móvil reconstruido con estadísticas compactas y controles accesibles.
- Mantiene PBR, tienda, ropa/disfraces, monedas, XP y progresión de V23.
- No requiere SQL nuevo desde V23.

El realismo final sigue condicionado por la geometría del GLB incluido; esta versión mejora materiales, luz, encuadre, movimiento y respuesta sin sacrificar rendimiento.
